
# 🛡️ CyberSafe Toolkit

### A Beginner-Friendly Python Cybersecurity Project

CyberSafe Toolkit is a Python-based educational project designed to help users understand common online security risks. It provides simple tools for password strength analysis, suspicious URL detection, and basic cybersecurity awareness.

## 🎯 Project Purpose

The main objective of this project is to explore basic cybersecurity concepts through practical Python programming and encourage safer online habits.

## ✨ Features

### 1. Password Security Analyzer
- Checks password length.
- Identifies uppercase and lowercase letters.
- Checks for numerical digits and special characters.
- Assigns a basic password strength score.

### 2. Suspicious URL Checker
- Examines URLs for basic warning signs.
- Checks HTTPS usage.
- Identifies certain suspicious characters and keywords.
- Displays potential security warnings.

### 3. Cybersecurity Awareness Guide
- Provides essential online safety tips.
- Encourages secure password practices.
- Promotes awareness of phishing and suspicious links.

## 🛠️ Tools and Technologies

- **Programming Language:** Python 3
- **Editor:** Visual Studio Code / GitHub
- **Version Control:** GitHub
- **Concepts:** Functions, conditional statements, loops, lists, strings and user input.

## ⚙️ Implementation

The project is implemented using Python's built-in features.

Separate functions are used for the password analyzer, URL checker and cybersecurity awareness guide. Conditional statements evaluate user input, while loops provide an interactive menu that allows users to access different features.

No external libraries or paid APIs are required.

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run the following command:

```bash
python main.py
```

5. Select an option from the displayed menu.

## 📌 Project Outcome

CyberSafe Toolkit demonstrates how fundamental Python programming concepts can be applied to a real-world topic.

Through this project, I gained practical experience in writing functions, handling user input, applying conditional logic, working with strings and lists, and documenting code using GitHub.

## ⚠️ Limitations

This is a beginner-level educational project. Its password scoring and URL checks are basic indicators, not professional security assessments. It cannot guarantee password security or determine whether a website is malicious.
